# 数据截取工具网站 - 设计思路与技术报告

## 一、项目概述

### 1.1 项目背景
本项目是一个基于Flask框架开发的地震数据截取工具网站，用于从FDSN Web Service接口获取地震波形数据。用户通过Web界面输入查询参数，系统自动访问目标数据服务并下载数据文件。

### 1.2 核心功能
- **数据查询与下载**：用户输入台网、台站、通道等参数，系统自动拼接URL并下载数据
- **访问记录管理**：记录所有用户访问请求，包括IP地址、查询参数、请求时间等
- **管理员权限控制**：管理员可查看访问记录，普通用户无法访问管理功能

## 二、系统架构设计

### 2.1 整体架构
采用经典的**MVC（Model-View-Controller）架构模式**：

```
┌─────────────────────────────────────────┐
│         前端层 (View)                    │
│  - index.html (数据查询界面)            │
│  - admin_login.html (管理员登录)        │
│  - records.html (访问记录查看)          │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│       控制层 (Controller)                │
│  - app.py (路由处理、业务逻辑)           │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│        数据层 (Model)                    │
│  - database.py (数据库操作)             │
│  - access_records.db (SQLite数据库)     │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│      外部服务                            │
│  - FDSN Web Service API                  │
└─────────────────────────────────────────┘
```

### 2.2 技术栈
- **后端框架**：Flask 3.0.0（轻量级、灵活）
- **数据库**：SQLite（轻量级、无需额外配置）
- **HTTP客户端**：requests 2.31.0（处理外部API调用）
- **前端技术**：原生HTML5 + CSS3 + JavaScript（无框架依赖，轻量高效）

## 三、功能模块设计

### 3.1 数据查询模块

#### 3.1.1 参数输入设计
- **用户友好的时间输入**：
  - 使用HTML5日期选择器（`<input type="date">`）和时间选择器（`<input type="time">`）
  - JavaScript自动将日期和时间格式化为API要求的格式（`YYYY-MM-DDTHH:MM:SS.sss`）
  - 用户无需手动输入`T`和毫秒部分，提升用户体验

#### 3.1.2 数据获取流程
```
用户提交表单 
  → 参数验证（前端+后端双重验证）
  → 构建API请求URL
  → 调用外部FDSN服务
  → 处理响应（成功/失败）
  → 返回文件下载或错误提示
```

#### 3.1.3 文件下载处理
- 使用Flask的`send_file`函数，通过`BytesIO`在内存中处理文件
- 自动生成有意义的文件名：`data_{net}_{sta}_{loc}_{cha}_{start_time}.mseed`
- 支持大文件下载，避免内存溢出

### 3.2 访问记录模块

#### 3.2.1 记录内容
系统记录以下信息：
- **用户信息**：IP地址（支持代理环境）
- **查询参数**：net（网络代码）、sta（台站代码）、loc（位置代码）、cha（通道代码）
- **时间信息**：start_time（开始时间）、end_time（结束时间）、request_time（请求时间）
- **状态信息**：status_code（HTTP状态码）、status_message（状态消息）、success（成功标识）

#### 3.2.2 数据库设计
```sql
CREATE TABLE access_records (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    ip_address TEXT NOT NULL,        -- 访问者IP
    net TEXT NOT NULL,                -- 网络代码
    sta TEXT NOT NULL,                -- 台站代码
    loc TEXT NOT NULL,                -- 位置代码
    cha TEXT NOT NULL,                -- 通道代码
    start_time TEXT NOT NULL,         -- 查询开始时间
    end_time TEXT NOT NULL,           -- 查询结束时间
    request_time TEXT NOT NULL,       -- 请求时间
    status_code INTEGER,               -- HTTP状态码
    status_message TEXT,               -- 状态消息
    success INTEGER DEFAULT 0         -- 成功标识（0/1）
)
```

#### 3.2.3 数据访问设计
- 使用上下文管理器（`contextmanager`）管理数据库连接，确保资源正确释放
- 使用`sqlite3.Row`工厂，返回字典形式的结果，便于模板渲染
- 支持分页查询，每页50条记录，避免数据量过大导致性能问题

### 3.3 权限管理模块

#### 3.3.1 权限控制设计
- **装饰器模式**：使用`@admin_required`装饰器保护需要管理员权限的路由
- **Session管理**：使用Flask的session机制存储登录状态
- **密码管理**：支持环境变量配置，提高安全性

#### 3.3.2 权限验证流程
```
用户访问受保护路由
  → 检查session中admin_logged_in标志
  → 未登录：重定向到登录页面
  → 已登录：允许访问
```

### 3.4 用户界面设计

#### 3.4.1 设计原则
- **简洁美观**：使用渐变背景、圆角卡片、阴影效果
- **响应式设计**：支持移动端和桌面端自适应
- **用户友好**：清晰的表单标签、帮助文本、错误提示

#### 3.4.2 交互体验优化
- **加载状态反馈**：提交表单时显示加载动画和提示文字
- **实时验证**：前端JavaScript验证时间格式和逻辑
- **错误提示**：使用Flash消息系统显示操作结果

## 四、安全设计

### 4.1 输入验证
- **前端验证**：JavaScript实时验证，提升用户体验
- **后端验证**：服务器端必填字段检查，防止恶意请求
- **参数清理**：使用`.strip()`去除空格，防止注入攻击

### 4.2 IP地址获取
支持多种代理环境下的真实IP获取：
```python
1. 检查 X-Forwarded-For 头（代理服务器）
2. 检查 X-Real-IP 头（Nginx反向代理）
3. 使用 request.remote_addr（直接连接）
```

### 4.3 会话安全
- 使用随机生成的secret_key
- Session存储在服务器端，客户端只保存session ID
- 管理员密码支持环境变量配置

## 五、数据库设计

### 5.1 设计特点
- **轻量级**：使用SQLite，无需额外数据库服务器
- **自包含**：数据库文件独立，便于备份和迁移
- **高效查询**：使用索引和分页，优化查询性能

### 5.2 数据操作封装
- **上下文管理器**：自动管理数据库连接的打开和关闭
- **异常安全**：确保连接在任何情况下都能正确关闭
- **字典返回**：使用Row工厂，简化数据访问

## 九、核心代码设计模式

### 9.1 装饰器模式
用于权限控制：
```python
@admin_required
def records():
    # 需要管理员权限才能访问
    pass
```

### 9.2 上下文管理器模式
用于数据库连接管理：
```python
with get_db() as conn:
    # 自动管理连接的打开和关闭
    pass
```

### 9.3 工厂模式
使用`sqlite3.Row`工厂，将查询结果转换为字典：
```python
conn.row_factory = sqlite3.Row
```

## 十、性能优化

### 10.1 数据库优化
- 使用分页查询，避免一次性加载大量数据

- 使用索引优化查询性能

### 10.2 前端优化
- 使用原生JavaScript，无框架开销

- 响应式设计，适配不同设备

### 10.3 内存管理
- 使用`BytesIO`处理文件，避免临时文件
- 及时释放数据库连接
- 合理设置超时时间（60秒）
